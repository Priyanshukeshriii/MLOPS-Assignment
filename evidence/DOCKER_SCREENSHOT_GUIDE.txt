DOCKER PRACTICAL SCREENSHOT CHECKLIST
=====================================

These commands must be run on your computer with Docker Desktop/Engine installed and running.
Open VS Code terminal in the project root: mlops-lab-7-9

1) Verify Docker is available
   docker --version
   docker info
   Screenshot: Docker version and engine information.

2) Build the API image
   docker build -t ml-inference-api:1.0 .
   Screenshot: terminal showing the completed build and final success message.

3) List the image
   docker image ls
   Screenshot: ml-inference-api image and tag 1.0.

4) Run the container
   docker run --name ml-api -p 8000:8000 ml-inference-api:1.0
   Keep this terminal open. In another terminal run:
   curl http://localhost:8000/health
   Screenshot: running container and successful health response.

5) Test prediction from the host (PowerShell)
   $body = @{ area_sqft=1450; bedrooms=3; bathrooms=2; age_years=8; distance_to_city_km=6.5; parking_spaces=1 } | ConvertTo-Json
   Invoke-RestMethod -Method Post -Uri http://localhost:8000/predict -ContentType 'application/json' -Body $body
   Screenshot: prediction response.

6) Inspect the container and logs
   docker ps
   docker logs ml-api
   Screenshot: container status and application logs.

7) Stop and remove the container
   docker stop ml-api
   docker rm ml-api

8) Optional Docker Compose check
   docker compose config
   docker compose up --build -d
   docker compose ps
   docker compose logs
   Screenshot: Compose services and their status.

IMPORTANT
---------
Do not use the pending-status screenshot as evidence of a successful Docker run. Capture the actual output from your computer after each command succeeds. If port 8000 is already occupied, use -p 8001:8000 and test http://localhost:8001 instead.

BEFORE BUILDING THE IMAGE
-------------------------
The Dockerfile uses Python 3.11. The prepared model artifact was created during verification with Python 3.13.5. To keep Python and Scikit-learn serialization versions aligned, create/activate a Python 3.11 environment, install requirements.txt, and run:
   python -m src.train
Then run the Docker build command above. This writes a fresh model artifact using the same Python runtime intended for the container.
